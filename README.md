## About This Repository

This repository contains real-time applications and live C++ examples
for Object Oriented Programming with C++.

The programs are based on Unit I, Unit II and Unit III and demonstrate
the practical use of Object-Oriented Programming concepts in real-world
applications.


# Unit I - Fundamentals of OOP

## 1. Smart Agriculture Sensor Monitor

This program models soil-moisture sensors used in smart agriculture.
Each sensor stores its sensor ID, moisture level and timestamp.

The program demonstrates classes, objects, encapsulation, constructors,
member functions and a vector of objects.


## 2. Student Attendance Management System

This program manages student attendance by storing the student's
roll number, name, total classes and attended classes.

It automatically calculates the attendance percentage and demonstrates
classes, objects, encapsulation, constructors and member functions.

## 3. E-Commerce Product Catalog

This program maintains product details such as product ID, product name,
price and stock quantity for an online store.

It demonstrates static data members, static member functions,
inline functions, constructors, destructors and encapsulation.


# Unit II - Inheritance

## 1. Employee Payroll System

This program manages different types of employees such as full-time
employees, part-time employees and interns.

It calculates salary according to the employee type and demonstrates
base and derived classes, inheritance, protected members,
function overriding and runtime polymorphism.


## 2. Digital Payment Gateway

This program simulates different digital payment methods such as
Credit Card, UPI and Net Banking.

It demonstrates abstract classes, pure virtual functions,
hierarchical inheritance and runtime polymorphism.


## 3. Vehicle Fleet Management

This program manages different types of vehicles such as trucks,
delivery vans and bikes.

It demonstrates inheritance, protected members, virtual functions,
function overriding and runtime polymorphism.


# Unit III - Polymorphism

## 1. CAD Shape Drawing System

This program represents different CAD shapes such as circles,
rectangles and triangles.

It calculates the area and displays each shape using an abstract
base class, pure virtual functions and runtime polymorphism.


## 2. Complex Number Calculator

This program performs arithmetic operations on complex numbers.

It demonstrates operator overloading for addition, subtraction,
multiplication and comparison of complex numbers.


## 3. Input Validation Service

This program validates different types of input such as marks,
payment amounts and names.

It demonstrates function overloading and compile-time polymorphism
using different versions of the validate() function.
