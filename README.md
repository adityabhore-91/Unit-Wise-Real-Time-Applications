## About This Repository

This repository contains unit-wise real-time applications and live C++ examples for the subject **Object Oriented Programming with C++**.

The programs demonstrate the practical use of Object-Oriented Programming concepts in real-world software applications.

## How to Compile

```bash
g++ -std=c++17 filename.cpp -o program
```

Run the program:

```bash
./program
```

For Windows:

```bash
g++ -std=c++17 filename.cpp -o program.exe
program.exe
```
